# telegUP — симулятор подарков Telegram

Локальный развлекательный симулятор в стиле gift-казино: кейсы с CS:GO-рулеткой,
апгрейдер, маркет, инвентарь, Telegram-шоп и мини-игры. Работает в браузере,
с опциональным общим топом и регистрацией через Supabase — никаких реальных
денег, блокчейна и Telegram API.

Как выложить сайт в интернет бесплатно: см. **[DEPLOY.md](DEPLOY.md)**.

## Быстрый запуск

```bash
npm install
npm run dev
```

Открой адрес, который выведет Vite (обычно http://localhost:5173).

Сборка продакшн-версии:

```bash
npm run build
npm run preview
```

## Стек

| Слой       | Технология                              |
| ---------- | --------------------------------------- |
| UI         | React 19 + TypeScript                   |
| Стили      | Tailwind CSS v4 (`@tailwindcss/vite`)   |
| Анимации   | Framer Motion                           |
| Состояние  | Zustand + `persist` (LocalStorage)      |
| Сборка     | Vite                                    |
| Иконки     | inline SVG                              |

Состояние хранится в LocalStorage текущего браузера — **отдельно для каждого
аккаунта**: `telegup:state:v2:u:<id>` (онлайн-аккаунт), `telegup:state:v2:l:<email>`
(локальный аккаунт) и `telegup:state:v2:guest` (без аккаунта). Настройки
устройства (тема, звук, переключатели владельца) общие для всех аккаунтов и
лежат в `telegup:state:v2:__device`. Поэтому новый аккаунт начинается с
чистого листа, а старый возвращается ровно таким, каким его оставили.
Кнопка «Полный сброс» в админке или очистка данных сайта удаляет сохранение.

Регистрация и онлайн (опционально): `/auth` — аккаунт Supabase; общий топ и поиск
игроков — `/app/leaders`. Без ключей Supabase приложение работает в локальном режиме.

## Реальные данные

Каталог подарков сгенерирован из открытого сайта-каталога `telegifter.ru`
(коллекции, модели, фоны, символы, тиражи, реальные TON-цены на Fragment-стиле).
Скрапер лежит в `scripts/scrape-telegifter.mjs` и написан на чистом Node:

```bash
# первичный сбор (долго, сайт троттлит)
node scripts/scrape-telegifter.mjs --concurrency 4

# дозапись недостающих коллекций (пропускает уже собранные)
node scripts/scrape-telegifter.mjs --concurrency 4
```

Скрипт скачивает картинки в `public/gifts/` и пишет `src/data/telegram-gifts.json`.
Редкость каждой модели/фона/символа считается из **реальной доли в тираже**:

| Доля в коллекции | Редкость     |
| ---------------- | ------------ |
| ≤ 0.6 %          | мифический   |
| ≤ 2.5 %          | легендарный  |
| ≤ 8 %            | эпический    |
| ≤ 22 %           | редкий       |
| больше           | обычный      |

Кейсы генерируются автоматически: четыре редкостных, по одному на каждую
коллекцию, тематические (милый, зверинец, кубки, магия, Дуров, праздники),
«Топ-маркет», а также кейсы фонов и символов. Шансы внутри кейса — честные
взвешенные вероятности, рулетка лишь показывает выпавший результат.

## Мини-игры

- **Crash** — множитель растёт, успей забрать до краша.
- **Mines 5×5** — открывай клетки, множитель растёт с каждой звездой.
- **PvP** — дуэль с ботом на случайных подарках.
- **Dice** — 0.00–99.99, ставка на «больше/меньше».
- **Монетка** — орёл или решка, ×2.
- **Колесо** — взвешенные сектора от ×0 до ×10.
- **Tower** — 8 этажей, на каждом 1 из 3 клеток — мина, ×1.32 за этаж.
- **Hi-Lo** — карты 1–13, каждое угаданное повышает банк на ×1.85.

## Скрытая админка

Открой `/admin` под аккаунтом владельца (Supabase-аккаунт с почтой владельца
и меткой `owner`). Остальным показывается «Доступ закрыт». Доступно:

- выдача/списание звёзд;
- бейджи профиля (овнер, основатель, разработчик, тестер, стафф, вип, ог, кит, прогер);
- Premium;
- поиск и выдача любого подарка, очистка инвентаря, полный сброс;
- поиск игроков и выдача знаков верификации (`owner`/`premium`/`basic`/`crown`)
  через серверную функцию `grant_mark`;
- статистика.

## Дисклеймер

> Это игра. Все подарки вымышлены, реальный вывод средств невозможен.

Проект не является азартной игрой, не связан с Telegram, Fragment, VIRUS GAME BOT
или каким-либо реальным сервисом. Названия, модели и цены подарков взяты из
открытого каталога подарков Telegram и используются только как игровой контент.
Звёзды, монеты и TON-цены здесь — виртуальные и не имеют денежной стоимости.
